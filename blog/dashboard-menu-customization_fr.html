Personnaliser le menu du tableau de bord LiaisonOS

Le menu des modes du tableau de bord est désormais piloté par un fichier JSON. Masquez les modes inutilisés, renommez les libellés, créez vos propres groupes — sans recompiler, avec rechargement en direct à la sauvegarde.

Sylvain Deguire (VA2OPS) · LiaisonOS 2.3.4

Pourquoi un menu piloté par JSON

Chaque opérateur LiaisonOS utilise un mélange de modes légèrement différent. Certains ne touchent jamais à ARDOP, d'autres n'ont pas encore de modem Mercury, certains veulent Winlink VARA HF en avant-plan tandis que d'autres vivent sur JS8Call. Jusqu'à la 2.3.4, le menu du tableau de bord était compilé dans le binaire — l'adapter signifiait recompiler depuis la source.

En 2.3.4, le menu devient des données. Un seul fichier JSON décrit chaque groupe, chaque carte de mode, chaque libellé et icône. Le tableau de bord le lit au démarrage et surveille les modifications. Modifiez, sauvegardez, le menu se rafraîchit sur place. Sans redémarrage.

Votre fichier d'overrides

LiaisonOS livre un menu par défaut — le même que vous voyez à l'installation. Vos personnalisations vont dans un fichier d'overrides séparé dans votre dossier personnel :

  • ~/.config/liaisonos/dashboard-menu.overrides.json — vos personnalisations, survit aux mises à jour

Le tableau de bord fusionne ce fichier avec les défauts intégrés à chaque rechargement. Le fichier est créé automatiquement au premier lancement avec documentation et exemples intégrés. Ouvrez-le pour voir toutes les options disponibles.

Ce que vous pouvez changer

Le fichier d'overrides supporte six types de modifications. Tous sont optionnels — laissez vide ce dont vous n'avez pas besoin.

  • hide_modes — liste d'IDs de modes à masquer du menu
  • hide_groups — groupes entiers à masquer (ex. retirer le groupe BBS si vous ne l'utilisez pas)
  • relabel — renommer un mode (ex. afficher « VarAC HF » au lieu de « VarAC (VARA Chat) »)
  • add_to_group — ajouter vos propres modes personnalisés à un groupe existant
  • custom_groups — définir entièrement de nouveaux groupes, avec leur propre titre et éléments
  • group_order — réorganiser les groupes ; les non listés suivent dans leur ordre par défaut

Masquer un mode inutilisé

La personnalisation la plus simple : retirer du menu un mode que vous n'utilisez jamais. Ouvrez ~/.config/liaisonos/dashboard-menu.overrides.json et ajoutez :

{
  "hide_modes": ["winlink-ardop", "chat-chattervox-bt"]
}

Sauvegardez. L'option ARDOP disparaît du sélecteur Winlink, et Chattervox (BT) disparaît du groupe Messagerie. Le mode masqué existe toujours — vous ne le voyez plus dans le menu. Retirez l'entrée pour le faire revenir.

Masquer un groupe entier

Si vous n'utilisez jamais de BBS, vous pouvez retirer tout le groupe BBS :

{
  "hide_groups": ["bbs"]
}

Le tableau de bord affiche maintenant Messagerie, APRS et Outils — c'est tout.

Renommer un mode

Utilisez le libellé qui vous convient :

{
  "relabel": {
    "varac":   "VarAC HF",
    "js8call": "JS8"
  }
}

Ajouter un groupe personnalisé

Regroupez vos modes les plus utilisés dans une section « Favoris » en haut du menu :

{
  "custom_groups": [
    {
      "id": "favorites",
      "title_en": "MY FIELD STACK",
      "title_fr": "MA STATION TERRAIN",
      "icon": "⭐",
      "items": [
        { "type": "mode", "id": "varac",   "label": "VarAC",   "strip_icon": "💬" },
        { "type": "mode", "id": "js8call", "label": "JS8Call", "strip_icon": "📻" },
        { "type": "mode", "id": "winlink-vara-hf", "label": "Winlink VARA HF", "strip_icon": "📧" }
      ]
    }
  ],
  "group_order": ["favorites", "messaging", "aprs", "bbs", "tools"]
}

Votre nouveau groupe MA STATION TERRAIN apparaît en premier, avec les trois modes que vous utilisez réellement. Tout le reste conserve sa place par défaut après.

Astuce : Le champ strip_icon est un emoji affiché en Mode Strip lorsque le tableau de bord est rétracté. Choisissez le symbole qui vous parle — 💬 pour le chat, 📧 pour le courriel, 🐺 pour Chattervox, etc. L'icône est rendue via Noto Color Emoji (livré avec LiaisonOS).

Rechargement en direct

Pas besoin de redémarrer QtDashboard. Le tableau de bord surveille le fichier d'overrides — lorsque vous sauvegardez dans votre éditeur, le menu se reconstruit en environ 200 ms. Essayez : ouvrez le fichier dans nano ou votre éditeur préféré, ajoutez "hide_modes": ["fldigi"], sauvegardez, et regardez le bouton fldigi disparaître du panneau latéral.

C'est ainsi que fonctionnera le futur éditeur visuel de menu en 2.3.5 (une app Flask, même modèle qu'et-radio) : il écrit dans le fichier d'overrides, le tableau de bord se recharge en direct, vous voyez le résultat instantanément sans jamais toucher au JSON vous-même.

Les deux interfaces partagent une seule config

Le même fichier d'overrides alimente le menu en mode Bureau (barre latérale) ET la grille de cartes en mode Tactile. Masquez un mode ici et il est aussi masqué sur votre tablette 7". Pas de duplication par interface.

En mode Strip — la barre latérale rétractée de 80 px nouvelle en 2.3.4 — vos modes récents affichent leur emoji strip_icon plus une étiquette courte dérivée de la config du menu.

Compatible avec les versions futures

Si vous mettez à jour LiaisonOS et qu'un mode que vous aviez masqué n'existe plus (nous l'avons retiré, vous l'avez renommé, peu importe), le fichier d'overrides ignore silencieusement cette entrée. Rien ne casse. La fusion est tolérante.

Pareil pour l'ajout de nouveaux modes : quand LiaisonOS 2.3.5 sortira et ajoutera un mode au groupe Messagerie, vous le verrez automatiquement — même avec des personnalisations lourdes. Le défaut système porte la mise à jour ; vos overrides ne décrivent que les deltas.

Réinitialiser aux défauts

Pour effacer vos personnalisations et revenir à la configuration d'origine :

rm ~/.config/liaisonos/dashboard-menu.overrides.json

Le tableau de bord recrée le fichier avec le contenu du modèle au prochain lancement.

À venir ensuite

En v2.3.5, l'éditeur de menu arrive — une app Flask qui transforme tout cela en interface point-and-click. Glisser les groupes pour réorganiser, basculer les modes avec une case à cocher, choisir des icônes depuis une grille. En coulisses, il écrit le même fichier JSON que vous pouvez modifier à la main aujourd'hui.

Le menu piloté par JSON est la fondation. Tout le reste se construit dessus.
