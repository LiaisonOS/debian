Radio Configuration — taming CAT, from cold rig to on-the-air

CAT, PTT, baud — the fiddliest part of any station setup. The LiaisonOS Radio Configuration editor turns it into a few fields, and in 2.4.5 adds one-click Hamlib model lookup, a live CAT test, a no-mode PTT transmit test, and Detect COM (so VARA FM always finds your radio) — you stop guessing. With worked settings for the Yaesu FT-891, FT-991A and Icom IC-7300.

Sylvain Deguire (VA2OPS) · LiaisonOS 2.4.5

Radio Configuration · CAT Control · Find… + Test CAT + PTT + Detect COM

The part everyone dreads

Getting a radio talking to a computer is the classic stumbling block: which Hamlib model number? what baud rate? how does PTT key — over CAT, a serial line, or VOX? Get one wrong and nothing works, usually with no clear error.

LiaisonOS tackles it by storing every radio as a small profile (a JSON file in radios.d). It ships a library of known-good stock radios, and the Radio Configuration editor lets you create or tweak your own in a simple window. Pick a radio to make it active, and from then on rigctld — the Hamlib control daemon the whole system shares — engages automatically the moment the rig's USB is connected.

What a profile holds

The top of the editor is just identity: Vendor and Model (which auto-generate the profile ID and filename), and the Bands the rig covers (HF / VHF / UHF). The rest is grouped into toggle-able sections — CAT Control, VARA FM, Bluetooth TNC, Audio — and you only fill in what your radio needs.

CAT Control — the three questions that matter

Enable CAT Control if your radio has computer control, and answer three things:

  • Hamlib Rig ID — the model number Hamlib uses for your radio (more on finding it below). 1 means "Dummy / no real CAT".
  • Baud Rate — the serial speed, which must match the rate set in the radio's own CAT menu.
  • PTT Method — how rigctld keys transmit: RIG (over the CAT command link — most modern rigs), RTS/DTR (assert that serial control line — common with sound-card interfaces), or NONE (don't key from software — VOX or an external keyer).

Two optional extras cover edge cases: Hamlib --set-conf for per-rig serial quirks (e.g. rts_state=OFF), and PTT Only Mode when you want the link for keying only, not full control. Leave CAT Control off entirely and LiaisonOS treats the rig as no-CAT — fine for an HT on a sound-card interface with VOX.

New in 2.4.5 — stop guessing

Setting those fields used to mean digging through manuals and the command line. Four new helpers in the editor do the hard parts for you:

🔎
Find…
Searches Hamlib's own model list by vendor/model and fills the Rig ID for you. Type "IC-7300" and pick the row — no more hunting for the right number.
✅
Test CAT
Reads the current frequency straight off the live, already-engaged rigctld. Green + a frequency = your radio's CAT is talking. Nothing to spawn, nothing to stop.
📡
PTT
A transmit test — like WSJT-X's — with no mode running. Click to key the rig through the live CAT; it goes green "ON AIR" when it's really transmitting, click again to stop. Auto-releases after 10 s so it can't stick.
🔌
Detect COM
In the VARA FM section: finds which Wine COM port actually reaches your radio and fills PTT Port for you. It's COM10 — and the button proves it, so you never look up a COM number again.
Why "live"? In LiaisonOS, rigctld comes up the instant the rig's USB is plugged in and stays engaged. So Test CAT doesn't start its own temporary link that would fight the running one — it simply asks the engaged rigctld "what frequency are you on?" and shows the answer. A pure, safe read-back.

VARA FM & the COM port

VARA FM runs under Wine, so it keys your radio through a Windows COM port — and historically that was the one setting people got wrong. In LiaisonOS the answer is always the same: COM10. That Wine port is wired to /dev/et-cat, the stable link to whatever rig (or DigiRig) is plugged in, so it reaches the radio no matter what the underlying device is called.

You shouldn't ever have to think about it. New profiles prefill COM10; the Detect COM button confirms it (and would flag any other port if your setup were unusual); and LiaisonOS re-links COM10 → /dev/et-cat every time VARA FM starts, so it can't drift. (A few older Icom profiles shipped COM5, which pointed at a dead serial port — corrected in 2.4.5 so every radio is on COM10.)

The rule of thumb: if VARA FM won't key the radio, don't hunt for a COM number — just press Detect COM. It tells you the right port in plain language and fills it in.

Worked examples — three popular rigs

These are solid starting points. After entering them, click Test CAT — a frequency means you're done.

Yaesu FT-891  HF + 6 m, compact mobile

Rig ID 1036  ·  Baud 38400  ·  PTT RIG

The FT-891 pairs cleanly with a DigiRig Mobile made for it: the DigiRig's accessory cable carries the audio, and a single USB cable handles both CAT and PTT. Set the radio's CAT RATE to 38400 to match; PTT is sent as a CAT command (RIG) over that same USB serial. Highlight: tiny footprint, 100 W HF — the go-to portable SSB/data rig, and the DigiRig keeps it to one tidy interface.

Yaesu FT-991A  HF/VHF/UHF all-mode

Rig ID 1035  (the FT-991 driver covers the 991A)  ·  Baud 38400  ·  PTT RIG

One USB cable gives you CAT and a built-in USB sound card. Set the radio's CAT RATE to 38400. The 991A enumerates two serial ports (an "Enhanced" CAT port and a second port) — LiaisonOS's /dev/et-cat symlink lands on the CAT one for you. Highlight: HF through 70 cm, all modes, CAT + audio over a single cable — a complete shack-in-a-box.

Icom IC-7300  HF + 6 m, SDR

Rig ID 3073  ·  Baud 115200  ·  PTT RIG

The digital-mode favourite: a single USB cable carries CI-V CAT and the USB audio codec. In the radio's CONNECTORS menu, set CI-V USB Baud Rate to 115200 (and leaving CI-V USB Echo Back ON helps). PTT over CAT (RIG) works; many ops also key via the USB port's send line. Highlight: built-in sound card + real-spectrum scope, zero extra interfaces.

CAT reads, but the rig won't transmit?

That's almost always the PTT Method. If Test CAT shows a frequency (so CAT is clearly fine) but keying does nothing, work through it: try RIG first, then RTS, then DTR — whichever your cable is wired for, and hit the PTT button after each until it turns green. No mode to launch, no guesswork: the button keys the rig directly so you can isolate PTT from CAT in seconds. A radio with no computer PTT at all? Use NONE and let the rig's VOX transmit on audio. (Keying transmits — use a dummy load or a clear frequency; the button auto-releases after 10 s either way.)
